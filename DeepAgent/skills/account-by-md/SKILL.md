# K-IFRS 회계 분개 스킬

## 이 스킬의 역할

사용자가 거래를 설명하면, K-IFRS 표준에 맞는 **복식부기 분개(Journal Entry)**를 생성합니다.

생성한 분개는 반드시 **검증 체크리스트**를 통과해야 하며, 통과하지 못하면 수정 후 다시 검증합니다.

## 참조 파일

이 스킬은 아래 두 참조 문서에 의존합니다. 분개 생성 시 반드시 참조하세요.

| 파일 | 내용 | 용도 |
|------|------|------|
| `references/chart_of_accounts.md` | K-IFRS 표준계정과목 147개 (Balance 속성 포함) | 계정과목 선택, Balance 방향 확인 |
| `references/transaction_patterns.md` | 47개 표준 분개 패턴 | 거래→분개 매칭 |

---

## 분개 생성 절차

사용자로부터 거래 설명을 받으면, 아래 순서를 따릅니다.

### Step 1: 거래 분석

거래 설명에서 다음을 파악합니다:
- **무엇이** 증가/감소했는가 (자산, 부채, 자본, 수익, 비용)
- **금액**은 얼마인가
- **부가세**가 포함되는 거래인가

### Step 2: 패턴 매칭 시도

`references/transaction_patterns.md`에서 거래 설명과 매칭되는 패턴을 찾습니다.

- 패턴의 **키워드**와 거래 설명을 대조합니다
- 매칭되면 해당 패턴의 분개 구조를 그대로 적용합니다
- 금액 변수를 사용자 제공 값으로 치환합니다
- `[해당 비용 계정]`, `[해당 자산 계정]` 같은 플레이스홀더는 거래 내용에 맞는 구체 계정으로 대체합니다

### Step 3: 패턴 미매칭 시 — 직접 추론

매칭되는 패턴이 없으면, 아래 **추론 규칙**과 `references/chart_of_accounts.md`를 참조하여 분개를 직접 구성합니다.

---

## 분개 추론 규칙

### 핵심 원리: 계정의 자연적 잔액(Natural Balance)

모든 계정에는 고유한 자연적 잔액 방향이 있습니다. `chart_of_accounts.md`의 `Balance` 열에 명시되어 있습니다.

| 계정 분류 | 자연적 잔액 | 증가 시 기입 | 감소 시 기입 | 예시 |
|-----------|-----------|------------|------------|------|
| 자산 (asset) | Debit | **차변** | 대변 | 현금, 매출채권, 재고자산, 유형자산 |
| 부채 (liability) | Credit | **대변** | 차변 | 매입채무, 차입금, 사채 |
| 자본 (equity) | Credit | **대변** | 차변 | 자본금, 이익잉여금 |
| 수익 (revenue) | Credit | **대변** | 차변 | 매출, 이자수익 |
| 비용 (expense) | Debit | **차변** | 대변 | 급여, 감가상각비, 이자비용 |

**적용 방법:**
1. `chart_of_accounts.md`에서 해당 계정을 찾는다
2. `Balance` 열을 확인한다 (debit 또는 credit)
3. 계정 잔액이 **증가**하면 → Balance 방향에 기입
4. 계정 잔액이 **감소**하면 → Balance 반대 방향에 기입

### Contra(차감) 계정 — 반드시 주의

차감 계정은 원래 분류와 **반대 방향**의 자연적 잔액을 가집니다. `chart_of_accounts.md`에서 ⚠️ 표시로 구분되어 있습니다.

| 계정 | 원래 분류 | 자연적 잔액 | 주의 |
|------|----------|-----------|------|
| 매출채권 대손충당금 | 자산 항목이지만 | **Credit** | 자산의 차감 |
| 재고자산평가충당금 | 자산 항목이지만 | **Credit** | 자산의 차감 |
| 유형자산 감가상각누계액 | 자산 항목이지만 | **Credit** | 자산의 차감 |
| 사채할인발행차금 | 부채 항목이지만 | **Debit** | 부채의 차감 |
| 자기주식 | 자본 항목이지만 | **Debit** | 자본의 차감 |
| 매출에누리와 환입 | 수익 항목이지만 | **Debit** | 수익의 차감 |

### 대차평균의 원리 (절대 규칙)

**모든 분개에서 차변 합계 = 대변 합계**

이 원칙은 예외 없이 적용됩니다. 분개를 구성한 후 반드시 합계를 확인하세요.

## 검증 체크리스트

분개를 생성한 후, 아래 4단계 검증을 **반드시** 수행합니다. 하나라도 실패하면 수정해야 합니다.

### Level 1: 대차 균형 ✅

- [ ] 차변 합계 = 대변 합계인가?
- [ ] 차변 항목이 최소 1개 이상 있는가?
- [ ] 대변 항목이 최소 1개 이상 있는가?
- [ ] 모든 금액이 0보다 큰가?

### Level 2: 계정과목 유효성 ✅

- [ ] 사용한 모든 계정이 `chart_of_accounts.md`에 존재하는가?
- [ ] Abstract(○) 표시된 계정을 분개에 직접 사용하지 않았는가?
  - ❌ "자산", "유동자산", "부채", "판매비와관리비" 등은 분류용이므로 사용 불가
  - ✅ "현금및현금성자산", "매출채권", "급여" 등 구체적 계정 사용
- [ ] 플레이스홀더(`[해당 비용 계정]` 등)를 구체 계정으로 대체했는가?

### Level 3: Balance 방향 적정성 ✅

- [ ] 각 계정의 기입 방향이 자연적 잔액과 일치하는가?
  - 일치하면 → 해당 계정의 **증가** 거래
  - 불일치하면 → 해당 계정의 **감소** 거래 (이것이 맞는지 확인 필요)
- [ ] Contra 계정의 방향을 혼동하지 않았는가?

### Level 4: K-IFRS 비즈니스 규칙 ✅

- [ ] **영업권 손상환입 금지**: 영업권(goodwill)과 손상차손환입이 동시에 등장하면 **오류** (IAS 36.124)
- [ ] **소계 계정 사용 금지**: 매출총이익, 영업이익, 당기순이익 등은 분개 계정이 아님
- [ ] **감가상각누계액 차변 기입**: 유형자산 처분 거래가 아닌데 감가상각누계액이 차변에 있으면 재확인
- [ ] **자기주식 대변 기입**: 자기주식 처분/소각 거래가 맞는지 확인

## 출력 형식

분개를 사용자에게 제시할 때 아래 형식을 사용합니다.

```
[분개] {거래 설명}
  패턴: {패턴명} (또는 "직접 추론")
──────────────────────────────────────────
  구분     계정과목                    금액
──────────────────────────────────────────
  (차)   {계정과목명}           {금액 (천단위 콤마)}
  (차)   {계정과목명}           {금액}
    (대)   {계정과목명}           {금액}
    (대)   {계정과목명}           {금액}
──────────────────────────────────────────
  차변 합계                     {합계}
  대변 합계                     {합계}
  → ✅ 대차 균형 (또는 ❌ 대차 불균형)
```

추가로 경고나 참고사항이 있으면 아래에 표시합니다:

```
⚠️ 경고: {내용}
ℹ️ 참고: {내용}
```

## 사용자 응대 가이드

### 정보가 부족한 경우

사용자가 금액이나 세부 정보를 제공하지 않으면, **분개 구조만 먼저 보여주고** 빈 칸에 금액을 넣어달라고 요청합니다.

### 여러 해석이 가능한 경우

하나의 거래가 여러 방식으로 분개될 수 있으면, 각 경우를 제시하고 사용자에게 선택하게 합니다.

### 패턴 외 거래

패턴에 없는 복잡한 거래 (예: 복합금융상품, 기업결합, 연결조정)도 추론 규칙을 적용하여 최선의 분개를 제시하되, 불확실한 부분은 명시합니다.

## 제한사항

1. **연결재무제표 연결조정 분개는 미포함** — 별도/개별 재무제표 기준
2. **업종별 특수 계정과목** (금융업, 건설업 등)은 부분 포함
3. **세무조정 분개**는 범위 밖 (회계 분개만 다룸)
4. **계정과목은 K-IFRS 2024 기준** — 향후 택소노미 개정 시 업데이트 필요
