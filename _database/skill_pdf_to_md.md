## PDF → MD 변환 스킬

K-IFRS 기준서 PDF 파일을 읽고 구조화된 Markdown 파일로 변환하는 절차.

### 1단계: PDF 구조 스캔

- `pymupdf` (fitz) 사용 — 프로젝트 `.venv`에 이미 설치됨
- 전체 페이지 수 확인 후, 처음 10~15페이지 + 주요 경계 페이지를 스캔하여 문서 구조 파악
- **TOC 페이지** 식별: `목  차`, `본 문`, `결론도출근거  목차`로 시작하는 페이지 → 스킵 대상
- **저작권** 페이지 (보통 page 2~3): 스킵 (본문에 포함하지 않음)
- **섹션 경계** 탐색: 의결, 적용사례, 결론도출근거, 기타 참고사항 등 키워드로 위치 파악

```python
import fitz, re

doc = fitz.open('path/to/file.pdf')
print(f'Total pages: {doc.page_count}')

def clean_page(text):
    return re.sub(r'^- \d+ -\n', '', text.strip()).strip()

# 구조 스캔
for i in range(len(doc)):
    c = clean_page(doc[i].get_text())
    fl = c.split('\n')[0].strip()[:100] if c else ''
    if any(k in fl for k in ['결론도출근거', '기타 참고사항', '의결', '적용사례', '국제회계기준과의', '주요 특징', '경과']):
        print(f'P{i+1}: {fl}')
    if c.startswith('목  차') or c.startswith('본 문'):
        print(f'P{i+1}: [TOC]')
```

### 2단계: 본문 추출 및 구조화

**자동화 스크립트 방식** (수동 10페이지씩 읽기 대신):
1. TOC/저작권 페이지를 제외한 모든 페이지의 텍스트를 한번에 추출
2. 페이지 번호 아티팩트(`- N -`) 제거
3. 줄 단위로 처리하여 마크다운 구조 생성

**문단 번호 패턴** (정규식):
```python
para_pattern = re.compile(
    r'^(한?\d+[A-Z]*(?:\.\d+[A-Z]*)?|'   # 1, 8A, 한2.1, 한139.1
    r'BC\d+[A-Z]*(?:\.\d+[A-Z]*)?|'       # BC1, BC6A, BC13N
    r'한BC\d+[A-Z]*(?:\.\d+[A-Z]*)?|'     # 한BC104.1
    r'IG\d+[A-Z]*)$'                       # IG1, IG11
)
```

**처리 루프 핵심 로직:**
- 문단 번호가 단독 줄로 나오면 → `**번호** 본문` 형태로 뒤따르는 줄들을 합침
- 섹션 헤더(목적, 적용범위 등) → `### 헤더`
- 대분류(의결, 결론도출근거, 기타 참고사항) → `## 대분류`
- `※` 주석 → `> ※ 내용` 블록쿼트
- `[결론도출근거]` 같은 대괄호 마커 → 스킵
- 각주 `N) 텍스트` → `[^N]: 텍스트`

### 3단계: 띄어쓰기 교정 (필요시)

일부 PDF는 한국어 텍스트에 띄어쓰기가 전혀 없음 (개념체계 등).
이 경우 `kiwipiepy` 사용:

```python
from kiwipiepy import Kiwi
kiwi = Kiwi()
corrected = kiwi.space(text)  # 한국어 자동 띄어쓰기
```

**후처리 필수:** kiwipiepy가 전문 용어를 과도하게 분리하므로 복합명사 복원 필요:
- `개념 체계` → `개념체계`, `회계 기준` → `회계기준`
- `재무 보고` → `재무보고`, `경제적 자원` → `경제적자원`
- `의사 결정` → `의사결정`, `표현 충실성` → `표현충실성`
- `제1 장` → `제1장` 등 60+개 전문 용어 패턴

**판단 기준:** PDF의 `get_text()` 결과에 띄어쓰기가 이미 있으면(대부분의 기준서) kiwipiepy 불필요. 개념체계처럼 붙어있는 경우에만 적용.

### 4단계: 표(Table) 검수 및 재구성

**핵심 문제:** `fitz.get_text()`로 추출하면 PDF 내 표(재무제표, 계산 예시 등)의 열/행 구조가 완전히 사라짐. 숫자가 문단번호로 오인되어 `**숫자**` 형태로 깨짐.

**검수 방법:**
```bash
# 숫자만 있는 볼드 줄 = 깨진 표 흔적
grep -n '^\*\*[0-9]\+\*\*\s*$' output.md
# 단위 표시 = 표 시작점
grep -n '단위.*원\|20X.*년' output.md
```

**수정 방법:**
1. PDF 원본 해당 페이지를 `doc[page].get_text()`로 확인하여 표 데이터 파악
2. 항목명 + 숫자 열을 식별하여 마크다운 테이블로 수동 재구성
3. `Edit`으로 깨진 영역을 교체

**표 포맷 규칙:**

| 규칙 | 예시 |
|---|---|
| 기본 형식 | `\| 항목 \| 20X7년 \| 20X6년 \|` |
| 정렬 | 숫자 열은 우측 정렬 `---:` |
| 소제목 행 | `\| **소제목** \| \| \|` |
| 합계/소계 | `\| **합계** \| **금액** \| **금액** \|` |
| 표 제목 | `#### 표 제목` + `(단위: 천원)` |
| 주석 | 표 아래 `> ⑴ 주석 내용` |
| 7열 이상 복잡한 표 | 연도별로 분리하여 가독성 확보 |

**표가 많은 기준서:** 제1001호(IG 재무제표 예시 15개), 제1007호(현금흐름표 예시 12개), 제1012호(부록 B 사례 1~8)

### 5단계: MD 파일 작성 포맷 규칙

| 원본 요소 | 마크다운 변환 |
|---|---|
| 문서 제목 | `# 기업회계기준서 제NNNN호 제목` |
| 기관명/의결일 | `**한국회계기준원 회계기준위원회**` + `**의결 YYYY. M. D.**` |
| ※ 안내문구 | `> ※ 내용` |
| 대분류 (의결, 결론도출근거, 기타참고사항) | `## 섹션명` |
| 중분류 (목적, 적용범위, 인식, 측정 등) | `### 소제목` |
| 소분류 (표 제목, BC 하위 주제 등) | `#### 소소제목` |
| 문단 번호 (1, 한2.1, BC1 등) | `**번호** 본문` (한 줄) |
| 열거 항목 | `⑴ ⑵ ⑶` (PDF 원본 유니코드 유지) |
| 재무제표/계산 표 | 마크다운 테이블 `\|...\|` |
| 각주 | `[^n]: 텍스트` |
| 인용/참고 안내 | `> 블록쿼트` |
| 페이지 번호 (`- 2 -` 등) | 제거 |

### 6단계: 문서 구조 순서 (K-IFRS 기준서 공통)

```
# 기업회계기준서 제NNNN호 제목
**한국회계기준원 회계기준위원회**
**의결 YYYY. M. D.**

> ※ 안내문구

> 기업회계기준서 제NNNN호는 문단 N~M으로 구성...

### 목적 / 적용 / 적용범위 / 용어의 정의
(본문 문단들: **1** ... **한2.1** ...)

### 인식 / 측정 / 표시 / 공시 등
(본문 문단들 계속)

### 시행일과 경과규정
## 의결
## 적용사례 (있는 경우)
## 결론도출근거
  > BC 참고사항 안내
  ### IAS N의 결론도출근거
  (BC 문단들)
  ### IAS N에 대한 소수의견
  ### K-IFRS 제NNNN호의 결론도출근거 (있는 경우)
## 기타 참고사항
  ### 국제회계기준과의 관계
  ### 이 기준서의 주요 특징
  ### 제·개정 경과
```

### 7단계: 출력

- 출력 경로: `output/raw_md/{원본 PDF 파일명}.md`
- 기존 파일이 있으면 덮어쓰기 (기존은 OCR 품질 불량)
- 파일명은 원본 PDF 파일명과 정확히 일치시킬 것 (언더스코어/공백 주의)

**Why:** 기존 raw_md 파일들은 자동 OCR 변환으로 헤딩 구조가 엉망이고, 불필요한 공백/페이지 번호가 포함되어 있으며, 표가 완전히 깨져 있어 RAG 청킹 품질이 낮음. fitz 기반 구조화 + 표 수동 검수가 필요.

**How to apply:** 사용자가 PDF 파일 경로를 주고 "MD로 만들어줘" 또는 유사한 요청을 하면 이 절차를 따라 변환 수행. 표가 있는 기준서(특히 적용사례/부록 B가 있는 경우)는 반드시 4단계 검수를 수행할 것.
