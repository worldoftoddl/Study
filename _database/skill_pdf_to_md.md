## PDF → MD 변환 스킬

K-IFRS 기준서 PDF 파일을 읽고 구조화된 Markdown 파일로 변환하는 절차.

### 1단계: PDF 읽기

- `pymupdf` (fitz) 사용 — 프로젝트 `.venv`에 이미 설치됨
- `poppler-utils`는 미설치(sudo 권한 없음), Read 도구로 PDF 직접 읽기 불가
- 10페이지씩 나눠 읽기 (`range(0,10)`, `range(10,20)`, ...)
- 전체 페이지 수 먼저 확인 후 분할 계획

```python
import fitz
doc = fitz.open('path/to/file.pdf')
print(f'Total pages: {doc.page_count}')
for i in range(start, end):
    text = doc[i].get_text()
```

### 2단계: 기존 MD 파일 포맷 확인

- `output/raw_md/` 디렉터리의 기존 파일을 먼저 읽어서 스타일 참고
- 기존 파일은 OCR 기반으로 포맷이 불량한 경우가 많음 → 새로 작성

### 3단계: MD 파일 작성 포맷 규칙

| 원본 요소 | 마크다운 변환 |
|---|---|
| 문서 제목 | `# 제목` |
| 대분류 섹션 (저작권, 목차, 결론도출근거 등) | `## 섹션명` |
| 중분류 (목적, 적용범위, 원칙 등) | `### 소제목` |
| 소분류 (경영진의 관점, 자원, 위험 등) | `#### 또는 #####` |
| 문단 번호 (1, 2, BC1 등) | `**번호**` 볼드 + 본문 |
| 열거 항목 (1), (2), (3) | `⑴ ⑵ ⑶` 유니코드 번호 |
| 표 (목차, 구성요소 등) | 마크다운 테이블 `\|...\|` |
| 인용문 (SEC 규정 등) | `> 인용` 블록쿼트 |
| 각주 | `[^n]` 마크다운 각주 문법 |
| 기관명/날짜 등 메타 | `**볼드**` |
| 안내문구 (번역 면책 등) | `> 블록쿼트` |
| 용어 정의 | `**용어** — 정의내용` |
| 페이지 번호 (`- 2 -` 등) | 제거 |
| 줄바꿈 하이픈 연결 | 합쳐서 한 문장으로 |

### 4단계: 문서 구조 순서 (K-IFRS 기준서 공통)

1. 제목 + 기관명 + 날짜
2. 안내문구 (번역 면책)
3. 저작권 (한국어)
4. COPYRIGHT NOTICE (영문)
5. 목차 (테이블)
6. 본문 (문단 번호순)
7. 부록 (정의된 용어 등)
8. 결론도출근거 (BC 문단)
9. 적용사례/적용지침 (있는 경우)
10. 기타 참고사항 (번역경과, 개요 IN 문단)

### 5단계: 출력

- 출력 경로: `output/raw_md/{원본 PDF 파일명}.md`
- 기존 파일이 있으면 덮어쓰기 (기존은 OCR 품질 불량)

**Why:** 기존 raw_md 파일들은 자동 OCR 변환으로 헤딩 구조가 엉망이고, 불필요한 공백/페이지 번호가 포함되어 있어 RAG 청킹 품질이 낮음. 수동 구조화가 필요.

**How to apply:** 사용자가 PDF 파일 경로를 주고 "MD로 만들어줘" 또는 유사한 요청을 하면 이 절차를 따라 변환 수행.
