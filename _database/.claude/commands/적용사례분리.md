지정된 K-IFRS 기준서의 적용사례(IE/실무적용지침) 섹션을 원본 DOCX에서 재추출하여 별도 MD 파일로 분리합니다.

## 입력

- `$ARGUMENTS`: 대상 기준서 번호 (예: `1001`, `1109`, `1115`)
- 인자가 없으면 사용자에게 기준서 번호를 물어봅니다.

## 절차

### 1단계: 대상 파일 식별
- `output/docx_md/` 에서 해당 기준서 번호가 포함된 MD 파일을 찾습니다.
- `data/raw/IFRS_docx/` 에서 대응하는 원본 DOCX 파일을 찾습니다.
- 현재 MD 파일에서 `## 적용사례` 섹션이 존재하는지 확인합니다. 없으면 "적용사례 섹션이 없습니다"라고 알리고 종료합니다.

### 2단계: 현재 상태 진단
- 현재 MD 파일의 `## 적용사례` 섹션을 읽어 테이블 깨짐 여부를 파악합니다.
  - 금액 열 누락 (1열짜리 테이블), 테이블 분할, 빈 셀 연속 등
- 진단 결과를 사용자에게 보고합니다.

### 3단계: 원본 DOCX에서 적용사례 추출
- python-docx로 DOCX 파일을 엽니다.
  - **주의**: 이 프로젝트의 DOCX 파일은 ZIP 내부 경로가 백슬래시(`\`)로 되어 있어 직접 열 수 없습니다. ZIP을 메모리에서 경로 구분자를 `/`로 변환한 후 로드해야 합니다.
- 적용사례 섹션에 해당하는 문단(paragraph)과 테이블(table)을 순서대로 추출합니다.
- 테이블을 마크다운으로 변환할 때:
  - 모든 행의 모든 셀에서 빈 열(구분선 역할)은 제거합니다.
  - 완전히 빈 행은 제거합니다.
  - 병합 셀(동일 텍스트 반복)은 단일 셀로 축소합니다.
- 적용사례 텍스트(IG 문단 등)도 함께 포함합니다.
- 결론도출근거(`## 결론도출근거`) 이전까지만 추출합니다.

### 4단계: 파일 저장
- 출력 경로: `output/docx_md/적용사례/IE_K-IFRS_{번호}_{제목}.md`
- `적용사례/` 디렉토리가 없으면 생성합니다.
- 저장 전 연속 빈 줄(3줄 이상)을 단일 빈 줄로 정리합니다 (`re.sub(r'\n{3,}', '\n\n', content)`).

### 5단계: 완전성 검증
- 원본 DOCX 적용사례 테이블의 **고유 금액**을 추출합니다 (병합 셀 중복 제거).
- 복원 MD 파일의 금액과 대조합니다.
- **DOCX에만 있고 MD에 없는 금액이 0건**이어야 통과입니다.
- 검증 결과를 사용자에게 보고합니다:
  ```
  === 완전성 검증 ===
  DOCX 고유 금액: N개
  MD 고유 금액: M개
  누락: 0개 ✓ (또는 X개 — 누락 목록 표시)
  ```

### 6단계: 원본 MD에서 적용사례 제거
- 검증 통과 시, 원본 MD 파일에서 `## 적용사례` 부터 다음 `## ` 헤더 직전까지 삭제합니다.
- 검증 실패 시, 삭제하지 않고 사용자에게 알립니다.

### 7단계: 결과 보고
```
=== 적용사례 분리 완료 ===
기준서: K-IFRS 제{번호}호 {제목}
추출 파일: 적용사례/IE_K-IFRS_{번호}_{제목}.md ({N}줄)
원본 MD: {삭제된 줄}줄 제거
완전성: DOCX 고유 금액 {N}개 중 {N}개 통과
```

## 규칙

- 적용사례가 없는 기준서(해석서 등)는 건너뜁니다.
- 추출 스크립트를 매번 새로 작성하지 않고, `pipeline/extract_ie_tables.py`의 로직을 참고하되 대상 기준서에 맞게 조정합니다.
- 이미 `적용사례/` 에 해당 파일이 존재하면 덮어쓰기 전에 사용자에게 확인합니다.
- 결론도출근거(BC) 영역은 절대 포함하지 않습니다.
