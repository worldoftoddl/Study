# K-IFRS 복합 분석 프레임워크

## 사용 시점
- 질문이 2개 이상의 기준서에 걸쳐 있을 때
- 인식/측정 판단에 여러 조건을 분기해야 할 때
- 기준서 간 교차 참조가 필요할 때

## 5단계 분석 절차

### 1단계: 질의 분해
write_todos를 사용하여 질문을 구체적인 하위 과제로 분해합니다.

예시:
```
질의: "계약체결 증분원가는 언제 자산으로 인식?"
→ [ ] 1115호에서 계약체결 증분원가 관련 문단 검색
→ [ ] 자산 인식 요건 및 상각 기준 분석
→ [ ] 관련 교차 참조 기준서 식별
→ [ ] 종합 판단
```

### 2단계: 관련 기준서 식별
질문에서 직접 언급된 기준서 외에, 교차 참조될 수 있는 기준서를 식별합니다.

주요 교차 참조 패턴:
- 1115호(수익인식) ↔ 1037호(충당부채) ↔ 1109호(금융상품)
- 1016호(유형자산) ↔ 1036호(자산손상) ↔ 1023호(차입원가)
- 1002호(재고자산) ↔ 1036호(자산손상) ↔ 1041호(농림어업)
- 1019호(종업원급여) ↔ 1026호(퇴직급여제도)
- 1038호(무형자산) ↔ 1036호(자산손상) ↔ 1103호(사업결합)

### 3단계: 기준서별 개별 분석
kifrs-expert 서브에이전트를 기준서별로 병렬 실행합니다.

- task 설명에 기준서 번호와 구체적 질문을 명시
- 독립적인 기준서 분석은 반드시 병렬로 실행
- 서브에이전트는 분석 결과를 /memo/{기준서번호}_analysis.md에 저장

### 4단계: 교차 적용 및 종합 판단
서브에이전트 결과를 종합하여:
- 각 기준서의 인식/측정 요건을 대조
- 조건별 분기 판단 수행
- 결론을 /memo/cross_ref.md에 정리

### 5단계: 자기 검증
최종 답변 전에 점검합니다:
- 인용한 기준서 문단이 정확한가?
- 생략된 판단 단계가 있는가?
- 교차 참조해야 할 기준서를 빠뜨리지 않았는가?
- 결론이 기준서 원문과 모순되지 않는가?

## 답변 형식
- 모든 판단에 기준서 번호와 문단 번호를 인용 (예: K-IFRS 1115호 문단 91)
- 복수 기준서 적용 시 각 기준서별 근거를 구분하여 제시
- 불확실한 판단이 있으면 명시적으로 언급

## 교차참조 판단 체크리스트

답변 초안을 작성한 뒤 반드시 확인:

□ 질의의 모든 조건(시점, 지급방식, 해지조항 등)을 답변에 반영했는가?
□ 하나의 기준서만으로 결론을 내렸는가?
  → 그렇다면 다른 기준서 적용 가능성을 재검토하라
□ "계약 체결시점"처럼 단정한 부분이 있는가?
  → 그 판단의 전제 조건을 명시했는가?
□ 인용한 사례(IE)가 질의 상황과 동일한 조건인가?
  → 조건이 다르면 사례 적용을 철회하라
